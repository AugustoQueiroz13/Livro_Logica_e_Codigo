## 📖 Sobre o Livro

Bem-vindo ao repositório oficial do livro **"Lógica & Código: Fundamentos da Programação em Python com IA"**.

## 🚀 Como Executar

Para rodar os exemplos na sua máquina, você precisará ter o **Python** instalado. Você pode simplesmente copiar e colar o código ou segur as instruções abaixo:

### 1. Clone este repositório
Abra seu terminal (ou Git Bash) e digite:

```bash
git clone [https://github.com/AugustoQueiroz13/Livro_Logica_e_Codigo.git](https://github.com/AugustoQueiroz13/Livro_Logica_e_Codigo.git)
```

### 2. Acesse a pasta do projeto
```bash
cd Livro_Logica_e_Codigo
```
### 3. Execute um arquivo específico
Por exemplo, para rodar o desafio do Jogo da Adivinhação:
```bash
python Capitulo_03/jogo_adivinhacao.py
```
**Dica do Autor**: Recomendo o uso do **VS Code** com a extensão do **GitHub Copilot** para estudar estes códigos, conforme sugerido na conclusão do livro.
